# Admin Panel CMS

A secure and scalable **content management system** built with the **MERN stack**, featuring authentication, role-based access control, and real-time content management with cloud integration.

---

## <img width="18" src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/react/react-original.svg" /> Overview

This project provides a centralized dashboard to manage and update content dynamically. It implements **admin and user roles**, **JWT-based authentication**, **CRUD operations**, and **Cloudinary integration** for media handling — all styled with **TailwindCSS** for a clean, responsive UI.

---

## <img width="18" src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/nodejs/nodejs-original.svg" /> Tech Stack

- **MERN Stack** (MongoDB, Express.js, React, Node.js)  
- **TailwindCSS** – for modern, responsive UI  
- **JWT Authentication** – secure session handling  
- **Cloudinary** – image storage and CDN optimization  
- **RESTful CRUD APIs** – backend resource management  

---

## <img width="18" src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/express/express-original.svg" /> Features

- **User Authentication:** Secure login/signup using JWT  
- **Role-Based Access:** Admin vs. Standard User privileges  
- **Content Management:** Add, edit, delete, and view data dynamically  
- **Cloudinary Integration:** Upload and manage images seamlessly  
- **Responsive Dashboard:** Built with TailwindCSS for all screen sizes  
- **Real-Time Updates:** Instant content reflection with efficient state sync  

---

## <img width="18" src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/mongodb/mongodb-original.svg" /> Authentication Flow

1. User signs in using credentials  
2. Server validates credentials and returns a **JWT**  
3. Client stores the token in memory/localStorage  
4. Each protected route request includes the token in headers  
5. Server verifies token → grants/denies access
